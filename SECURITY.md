# Security policy

## Reporting a vulnerability

Please report security and privacy problems privately, not in a public issue.

Use GitHub's private reporting: open the repository's **Security** tab and choose
**Report a vulnerability**. Only the maintainer can see the report.

Useful details: what happens, the Ramblr version, your device and Android
version, and steps to reproduce. A proposed fix is welcome but not required.

You'll get a reply as soon as possible. Once a fix is released, the report can be
made public, with credit to you if you'd like.

## Supported versions

Only the latest release gets fixes. Ramblr updates itself (GitHub build) or
through your store, so please check you're on the latest release before reporting.
